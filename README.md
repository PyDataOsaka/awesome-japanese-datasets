## 雇用・労働

- [企業別 面接質問コーパス（1,779問 / 472社、CSV・出典URL付き）](https://part676392.github.io/dsh-money-engine/?src=prpydata) — 公開の就職・キャリア記事 600 本から抽出した面接質問を企業単位に対応付けたデータ。選考フロー 96 本と段階別の引用 2,021 件を含む。抽出手順を公開しており再実行して検証できる
